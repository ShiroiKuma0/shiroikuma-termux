Bundled terminal styling assets for the 白い熊 Termux UI page.

colors/   The 122 colour schemes of termux/termux-styling (app/src/main/assets/colors, GPLv3 like
          the rest of that repository and this one), file names unchanged, plus the house scheme
          shiroikuma.properties (yellow on black).
fonts/    Four monospace fonts from the same repository, chosen for their permissive licences —
          each .ttf ships with the .txt licence note it came with:
            CascadiaCode          SIL Open Font License 1.1
            Fira-Code             SIL Open Font License 1.1
            Fantasque-Sans-Mono   SIL Open Font License 1.1
            Meslo                 Apache License 2.0
          Picking one copies it to ~/.termux/font.ttf, exactly as termux-styling did.
